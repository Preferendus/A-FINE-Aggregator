# A-FINE-Aggregator
An operational preference-aggregation procedure for applied MCDM. It aggregates commensurable preference 
information through a weighted centroid in the Linear Preference Space (LPS), which provides a stable zero
referenced interval scale and preserves uniqueness up to affine transformation, thereby enabling preference
consistent design–decision analysis and optimisation. Within the contemporary Preferendus software 
environment, the A-FINE Aggregator is implemented in the IMAP–IGS Solver Family for multi-objective design
decision optimisation (MODO) and in TOMAP for preference-based trade-off design–decision analysis (MCDA).
